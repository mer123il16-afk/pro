الإعدادات

الخادم (داخل هذا الملف)

محلي: شغّله في Termux ويتوقف بإغلاقه. دائم: شغّله على سيرفر بعيد داخل tmux، فيبقى يعمل حتى لو أُطفئ جوالك أو حُذف Termux. ضع عنوانه (HTTPS) في «عنوان الخادم».

# مفاتيحك (تُكتب في Termux فقط، لا تلصقها بالمحادثة)
export HF_TOKEN="hf_..."       # نموذج قوي من Hugging Face بدون تحميل على جوالك
export GITHUB_TOKEN="ghp_..."  # لجلب مستودعاتك الخاصة

# نموذج مجاني محلي (بدون مفتاح ولا إنترنت)
a) pkg install ollama
b) جلسة Termux 1: ollama serve
c) جلسة Termux 2: ollama pull qwen2.5:3b
d) بعدها شغّل الخادم بدون ANTHROPIC_API_KEY وسيستخدمه تلقائيًا

# تشغيل محلي على الجوال (الأسهل)
1) pkg install python
2) ضع assistant_server.py و assistant.html في نفس المجلد
3) export ANTHROPIC_API_KEY="..."
4) python assistant_server.py
5) افتح http://127.0.0.1:8765 في المتصفح (لا تفتح الملف مباشرة)
6) يشتغل فقط وانت مشغّله؛ تسكر Termux يوقف ولا يستهلك شي

# على الجهاز البعيد (مرة واحدة)
1) ثبّت: python3 و tmux ووكيل HTTPS (Caddy أو cloudflared)
2) tmux new -s ast
3) export ANTHROPIC_API_KEY="..."
4) export ASSISTANT_PUBLIC_HOST=ast.example.com
5) الصق الأمر المنسوخ من «إنشاء رمز جديد» وشغّله
6) اخرج بـ Ctrl+B ثم D (يبقى الخادم شغّالًا)
7) Caddyfile: ast.example.com { reverse_proxy 127.0.0.1:8765 }
8) في «عنوان الخادم» ضع https://ast.example.com ثم اختبر الربط

وضع المالك

يحمي إعدادات Termux. الرقم السري يُخزَّن مشفّرًا (PBKDF2) على هذا الجهاز.

الخبرات والشخصيات

  
مثل «خبير برمجة». تفعّلها بقول: صير + الاسم.

  

  

  


  
الدروس المحفوظة

  


  
الصوت

  
صوت بشري حقيقي (XTTS) من مولّدك، أنثى أو ذكر، أو استنساخ صوت من مقطع قصير (10 إلى 30 ثانية). استنسخ فقط أصواتًا تملك إذن استخدامها.

  
  
  

  
 


  
صور وفيديو من نموذجك أنت

  
بدون أي خدمة أو مفتاح خارجي. شغّل gen_server.py على جهاز فيه كرت شاشة NVIDIA (الجوال ما يكفي لتوليد الصور والفيديو)، وحط عنوانه ورمزه هنا. بعدها اكتب في المحادثة صورة: وصف أو فيديو: وصف، ومفتاحك يولّدهم من البوت أو أي برنامج.

  

  
  

  
مفتاحي وتجربته بأي مكان

  
المفتاح يخلّي أي برنامج أو بوت تلكرام يكلّم ذكاءك المدرَّب. التدريب يُرفع للخادم تلقائيًا.

  
لتغيير بادئة مفتاحك قبل تشغيل السيرفر: export ASSISTANT_KEY_PREFIX=sk-MOHANAD- (أحرف إنجليزية فقط).

  

  

  
كود بوت تلكرام جاهز: كتابة عادية = رد ذكي، /image وصف = صورة، /video وصف = فيديو (بدّل BOT_TOKEN بتوكن البوت):

  

  

  
إذا البوت على سيرفر غير جوالك، شغّل الخادم كذا: ASSISTANT_TUNNEL=1 python assistant_server.py (يحتاج cloudflared) وخذ العنوان العام اللي يطلع بدل 127.0.0.1.
