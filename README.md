# المساعد

ملفات المشروع: `assistant.html` (الواجهة) · `assistant_server.py` (الخادم) · `gen_server.py` (مولّد الصور والفيديو والصوت، يحتاج كرت NVIDIA) · `install.sh` (مثبّت واحد لـ Termux أو جهاز فيه كرت).

## تشغيله على استضافة (Render مثلًا)
1. ارفع كل الملفات إلى مستودع GitHub (يفضّل Private).
2. في Render: New ← Blueprint ← اختر المستودع (يقرأ `render.yaml` تلقائيًا).
3. بعد النشر: Environment ← انسخ قيمة `ASSISTANT_TOKEN`.
4. افتح رابط الموقع ← الإعدادات ← ألصق الرمز في خانة الاقتران.
5. أضف في Environment مفتاح النموذج الذي يستخدمه الخادم للمحادثة ، إما `ANTHROPIC_API_KEY` أو الثنائي `AI_API_KEY` و`AI_BASE_URL` (أي خدمة متوافقة مع OpenAI).

ملاحظات:
- الرمز مطلوب دائمًا على الاستضافة، فلا يستطيع أحد استخدام الخادم بدونه.
- الاستضافة المجانية تمسح ملفات التشغيل (المفاتيح، التدريب) عند كل إعادة نشر، ويلزم قرص دائم للاحتفاظ بها.
- الصور والفيديو والصوت لا تعمل على الاستضافة العادية (بلا كرت NVIDIA). شغّل `gen_server.py` على جهاز فيه كرت وضع عنوانه ورمزه في الإعدادات.
- Cloudflare لا يشغّل خادم Python، استعمله فقط لعرض `assistant.html`.
