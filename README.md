# المساعد

ملف واحد `assistant.py` يجمع الخادم والواجهة والذكاء الاصطناعي ومولّد الصور والفيديو والصوت.

## Termux (أول مرة فقط)
    pkg install python
    python assistant.py
ثم افتح http://127.0.0.1:8765 ← زر السكربتات ← **نسخ السكربت الكامل** ← افتح جلسة Termux جديدة والصق ← Enter.

السكربت الكامل يثبّت كل المتطلبات، وينسخ المساعد، ويشغّله في الخلفية ويعيد تشغيله إذا وقع. على جهاز فيه كرت NVIDIA يثبّت أيضًا متطلبات الصور والفيديو والصوت ويشغّل المولّد.
بعدها: `assistant` تشغيل · `assistant stop` · `assistant log` · `assistant status`

## استضافة (Render)
New ← Blueprint ← اختر المستودع. انسخ `ASSISTANT_TOKEN` من Environment وألصقه في إعدادات الواجهة، وأضف مفتاح النموذج في Environment.
الاستضافة المجانية تمسح المفاتيح والتدريب عند كل إعادة نشر.
